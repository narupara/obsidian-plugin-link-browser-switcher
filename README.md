# Link Browser Switcher

外部リンクをクリックしたとき、押しているキーの組み合わせによって
「どのブラウザで開くか」を切り替えられる Obsidian プラグインです。

| 操作 | 開くブラウザ |
|---|---|
| 素クリック | 既定のブラウザ（Obsidian標準の動作） |
| Ctrl + クリック | 設定画面で指定した「ブラウザA」 |
| Ctrl + Shift + クリック | 設定画面で指定した「ブラウザB」 |

対象は `http://` `https://` の外部リンクのみです。
ノート同士の内部リンク（`[[ノート名]]`）は対象外で、これまで通り動作します。

---

## インストール方法

1. `link-browser-switcher` フォルダごと、Vault内の
   `.obsidian/plugins/` フォルダにコピーする。

   ```
   （あなたのVault）\.obsidian\plugins\link-browser-switcher\
       ├─ main.js
       └─ manifest.json
   ```

   `.obsidian` フォルダが見当たらない場合は「隠しフォルダを表示する」設定に
   してください（Windowsのエクスプローラーでは「表示」タブ→「隠しファイル」に
   チェックを入れる）。

2. Obsidianを再起動する。

3. 設定（左下の歯車アイコン）→「コミュニティプラグイン」を開き、
   一覧から「Link Browser Switcher」を探してオン（有効化）にする。

   ※ 初めてコミュニティプラグインを使う場合は、「セーフモード」が
      オンになっていると有効化できません。まずセーフモードをオフにしてください。

---

## 設定方法（ブラウザのパスを登録する）

1. 設定画面の左メニュー、コミュニティプラグインの一覧の下の方に
   「Link Browser Switcher」というタブが増えているので開く。

2. 「ブラウザA」「ブラウザB」それぞれについて、
   - **表示名**：通知メッセージなどに表示される名前（例: Comet, Brave）
   - **実行ファイルのパス**：ブラウザの `.exe` ファイルの場所

   を入力する。

### 実行ファイルのパスの調べ方（Windows）

1. デスクトップやスタートメニューにあるブラウザのアイコンを右クリックする
2. 「プロパティ」を開く
3. 「リンク先」欄に表示されているパスをコピーする
   （例: `"C:\Program Files\BraveSoftware\Brave-Browser\Application\brave.exe"`）
4. 設定画面の「実行ファイルのパス」欄に貼り付ける
   （前後の `"` は付いていてもいなくても、どちらでも動作します）

---

## 動かない場合

- **クリックしても何も起きない**
  → 設定タブでパスが入力されているか確認してください。
    パスが空欄の場合は既定のブラウザで開く仕様になっています（通知が出ます）。

- **「実行ファイルが見つかりません」と出る**
  → パスが間違っている可能性があります。上記の「パスの調べ方」を参考に、
    もう一度パスを確認してください。

- **内部リンク（ノート同士のリンク）で意図せずブラウザが開いてしまう**
  → 通常は起きませんが、もし発生した場合はご自分で何とかしてください
    （href が http/https で始まるかどうかで判定しているため、
    通常のノートリンクでは発生しない想定です）。

## 今後の拡張について

- **右クリックメニューからのブラウザ選択**：今回のバージョンでは未実装ですが、
  `main.js` 内の `openWithBrowserSlot` 関数を右クリックメニューからも
  呼び出せる設計にしてあるため、後から追加しやすくなっています。
- **使い分けパターンを増やしたい（例: Ctrl+Alt+クリックでブラウザCを追加）**：
  `main.js` 冒頭の「カスタマイズゾーン」内、`BROWSER_SLOTS` という配列に
  項目を1つ追記するだけで、設定画面の入力欄・クリック時の判定の両方に
  自動的に反映されます。詳しい書き方はコード内のコメントを参照してください。
